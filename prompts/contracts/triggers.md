# 静态预筛信号契约

## status
以下为接口规格，尚未接入本地差分引擎；认识信号 ID 不代表已实现检测能力。
未实现检测、证据不完整或无法比较时返回 unknown，禁止用固定 false 占位。

## signals
| 信号 ID | 触发候选 | 判定 clear 的必要证据 |
| --- | --- | --- |
| delta:single-consumer-export | 新增跨文件导出只有一个已知消费方 | 前后符号对应及受影响范围消费关系完整；未解析消费关系须 unknown |
| delta:scope-chain-growth | 影响对象、文件、模块、调用链或状态传播范围增加 | 前后对应对象与所需影响关系完整，未知指标不得当作 0 |
| delta:internal-defensive-branch | 新增内部判空、默认值或错误拦截分支 | 前后分支、对象角色及输入契约已识别；内部角色不确定须 unknown |
| delta:empty-catch | 新增空处理或静默丢弃错误的候选 | 变更范围解析完整、前后对应及错误处理结构可判定 |

## evaluation
结构命中仅代表候选，是否合理由具体规则、真实输入契约和例外决定。
单消费方可能是合法模块边界，内部可空契约可能需要分支，不能仅凭信号扣分或重构。
新增信号须定义必要证据、未知条件及能力版本，再在路由中引用。
