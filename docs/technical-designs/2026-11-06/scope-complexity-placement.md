## 1. 评分约定

作用域、复杂度、代码位置分别评分，随后合成综合分。作用域使用局部/全局基础分及属性百分比加成；复杂度保持常规时间优先，死循环与内存泄漏采用高权重规则；复用统一纳入影响链路。以下数值参数与处理细则作为设计建议。

| 维度 | 首版权重建议 | 评分关注点 |
| --- | --- | --- |
| 作用域 S | 45% | 局部/全局基础分、属性百分比加成及链路影响 |
| 复杂度 C | 40% | 时间优先的常规成本及死循环、内存泄漏的高权重扣分 |
| 代码位置 P | 15% | 功能模块中的职责与位置适配程度 |

所有分数范围为 0–100，分数越高表示质量越好。完整结果使用：

```text
常规复杂度评分 = 0.60 × 时间评分 + 0.40 × 空间评分
C = 按严重问题规则处理后的复杂度评分
综合评分 = 0.45 × S + 0.40 × C + 0.15 × P
```

权重属于首版校准参数，各项成本或事实到分数的映射待定义。严重问题规则提高死循环与内存泄漏的扣分占比；具体系数、评分上限及与综合分的约束关系待标定。综合分的舍入规则及展示精度待确定。

## 2. 分析流程与职责

```text
源码快照、目标位置、功能模块配置、可选修改范围
                  ↓
AST 结构、符号绑定、引用、调用及数据流事实
                  ↓
       作用域分析 / 成本分析 / 位置分析
                  ↓
       三项评分、覆盖状态、证据与假设
                  ↓
         有效性检查与综合评分
```

事实采集、关系构建、三项分析、评分映射、结果合成分别承担单一职责。可复用的确定性运算抽离为纯函数。

通用文件定义入口和结果契约；语言、框架专项分别提供绑定、语义和框架关系等覆盖实现。专项缺项回退通用能力，通用结果保留支持范围与未解析项。

## 3. 作用域与链路

### 属性

对象类别、词法作用域、纯度、调用形式和生存期分别记录。一个函数可同时具有纯函数和立即执行属性；一个变量可同时属于局部变量和临时变量。

纯度依据返回值依赖与可观察副作用评估，记录共享可变状态、外部调用及条件假设。常量绑定的对象属性修改进入状态分析。立即执行函数产生的闭包、异步任务及返回对象按逃逸行为处理。

### 图与传播

- 节点标识绑定源码快照、声明位置及所属模块，符号解析处理同名遮蔽。
- 边区分调用、读取、写入、捕获、别名、导入导出及框架关系，保留来源和解析状态。
- 根据查询目的选取边类型：入站影响、出站调用、状态传播分别遍历。
- 方法、文件和模块按稳定标识去重；直接影响和传递影响分别统计。
- 复用通过调用与引用关系纳入链路；同一关系按边类型与端点去重，调用次数作为成本分析事实保存。
- 强连通分量记录递归或依赖环；压缩后的有向无环图按边数计算最长已知链路。
- 递归组大小、组间链路长度及运行时递归深度分别列示。
- 截断保留边界与已知链路下界；仓库外消费者及动态关系标记未知。

静态画像展示潜在传播范围。修改评估绑定前后快照，结合签名、实现、导出和状态变化筛选传播边，记录实际证据充分程度。

### 计分依据

基础分 B 按局部、全局两档选取。块级与函数内声明记录局部属性；模块级、类成员和导出声明保留详细作用域，其基础档位映射待确定。基础档位未知时记录待定状态。

纯函数、立即执行、临时性等属性满足各自规则时，按基础分的百分比加成。多项加成均以同一个 B 为基数累加。共享状态、捕获、逃逸及生存期参与属性资格判断；相关证据和假设随加成记录。

建议计算形式：

```text
属性加成 = B × 各项有效加成比例之和
S = clamp(B + 属性加成 − 链路影响扣分, 0, 100)
```

基础分数、属性比例、组合规则、加成上限及链路扣分映射待标定。重叠属性依据稳定规则去重，同一收益证据只归属一个加成项；未知属性保留状态。链路扣分结合状态传播、实际修改及影响范围计算。

复用数量、复用范围及跨模块复用只在链路计量中归属。属性加成使用纯度、隔离和生存期证据，位置评分使用职责适配证据。潜在受影响集合与必需修改集合分别输出。

## 4. 时间与空间复杂度

### 成本表达式

分析绑定具名输入规模和条件，输出时间 T(n, m)、峰值辅助空间 A(n, m) 及适用场景。最坏、平均和摊还成本分别标注；平均和摊还结论需记录相应假设。

| 结构 | 分析内容 |
| --- | --- |
| 固定次数循环 | 记录常量边界 k 及单次成本 |
| 连续循环 | 按执行顺序合并成本，例如 O(n + m) |
| 嵌套循环 | 结合边界依赖求和；独立规模可产生 O(nm) |
| 递归 | 递推关系、终止条件、分支数、深度及重叠子问题 |
| 缓存与记忆化 | 缓存命中条件、唯一状态数、缓存占用及生命周期 |
| 外部或动态调用 | 已声明成本契约、候选实现及未解析成本 |

递归调用栈计入辅助空间；临时分配按同时存活的峰值计算。输入、输出、缓存及辅助空间保留分类。单次函数执行和入口链路执行使用各自的成本边界。

仅在成本有证据且条件成立时给出相应增长阶。数据相关循环、动态分发、终止条件及外部实现无法确定时，返回部分表达式和未知项。

### 评分映射

时间、空间各自记录增长阶、成本界、任务预算与符合度。具名规模范围、允许的增长阶和预算来源随规则版本保存。不同任务职责使用明确的适用配置。

变量按初始化、更新或指定使用点归属计算成本，空间按对象分配与存活范围归属。同一运算在同一聚合结果中使用唯一计量标识。仅有声明的对象可返回复杂度项不适用状态。

缺少任务预算时可输出有证据的成本表达式；对应数值评分策略待确定。已证明无界、终止性未知及成本超预算分别记录。

### 死循环与内存泄漏

- 常规时间评分权重高于空间；死循环与内存泄漏各自具有高权重严重问题条目。
- 严重条目提高对应问题在复杂度评分中的扣分占比，记录规则、系数、实际扣分与合成贡献。
- 严重规则生效时，同一证据的扣分归属严重条目，常规成本条目保留事实和成本结论。
- 死循环判定记录输入条件、循环或递归的退出路径、阻塞与让出行为、取消信号及生命周期契约。约定的常驻循环按其契约检查。
- 内存泄漏判定记录分配、持有、释放责任及预期生命周期，覆盖对象非预期持续持有、资源释放遗漏和跨请求持续增长；预期缓存保留容量及淘汰约定。
- 证据状态区分已证实、疑似和未知，静态分析与运行观测分别标注来源。已证实问题进入严重扣分；疑似与未知保留诊断和覆盖状态，其评分有效性按规则处理。
- 代表性案例分别标定死循环与内存泄漏的扣分系数及评分约束，校验普通维度高分对严重结果的合成影响。

## 5. 代码位置与功能模块

模块配置声明边界、公共能力范围和入口。目录、文件名、导出关系、调用关系与框架关系作为补充证据。一个文件可包含多种角色，各对象保留自身角色。

| 文件职责与角色 | 职责适配的检查内容 |
| --- | --- |
| 公共入口 | 公共契约、输入边界、共享状态和对外职责 |
| 公共叶子 | 原子功能、输入输出、状态隔离和依赖边界 |
| 业务入口 | 参数接收、流程编排和模块边界 |
| 业务叶子 | 局部规则、数据处理和业务归属 |
| 中间处理 | 层次职责、跨模块依赖和编排边界 |

入口与叶子相对于所选功能模块及关系类型定义。关系覆盖充分且满足末端功能规则时确认叶子；存在未解析出边时保留候选状态。

位置评分使用职责适配规则。复用数量、影响方法数、文件数、模块数及链路长度统一在作用域的链路项计量；操作成本在复杂度项计量。位置和属性项不得按复用数量重复加扣分。

## 6. 有效性与结果信息

- 结果绑定仓库快照、目标声明、评估单元、模块配置和规则版本。
- 三项分别保存分数、子项、证据位置、假设、适用性及覆盖状态。
- 分析状态区分完成、部分完成、不支持和失败；适用性单独表达适用或不适用。
- 必需项未知时保留已完成评分，完整综合分进入待定状态；不适用项的合成策略待确认。
- 合成记录权重、各项贡献及舍入方式，显著问题保留独立诊断。
- 作用域保存基础档位、基础分、属性比例、各项加成、链路扣分及封顶结果；复杂度保存常规成本与严重问题的计分归属。
- 模块和仓库聚合需声明对象集合、去重规则及权重，聚合公式待确定。
- 相同输入与规则产生可复现的 internal 评分；模型评分保留提示词版本及原始响应。
- 仓库健康度等级选择执行限制；三项原始评分使用固定版本的标准。

## 7. 能力依赖与验收

当前 AST 提供选取的语法和结构事实。JS/TS 已有的局部作用域辅助能力用于语法识别；完整项目级符号、跨文件引用、调用图、数据流及成本分析属于后续接入范围。各后端须按能力独立验收。

验收案例覆盖同名遮蔽、闭包、全局读写、对象别名、纯函数复用、立即执行函数逃逸、循环规模、递归栈、记忆化、环路去重、动态调用及框架入口。每例提供输入、预期事实、成本条件、位置角色及评分预期。

评分案例同时覆盖局部与全局基础档位、多属性按基础分累计加成、加成封顶、复用链路去重及跨维度计分归属。严重问题案例覆盖死循环、常驻事件循环、终止性未知、内存泄漏、预期缓存和对象释放，检查证据状态、高权重贡献与最终综合结果。

参数校准使用代表性案例的人工排序，检查各子项贡献、重复计分和权重敏感性。计分规则及映射确认后形成实现任务与可执行契约。
