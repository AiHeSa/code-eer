# 作用域评分算法

- 日期：2026-11-07
- 标识：SCP-S / scope-evidence-1
- 状态：词法事实和本地结构指标已实现；下列语义推导与数值映射是实现规格。
- 依据：[原设计](../2026-11-06/scope-complexity-placement.md)、[采集契约](assessment-collection.md)

## 1. 输入与评估单元

变量按绑定评估，函数按声明及函数体评估；同名绑定不会合并。
输入包含 scopes、declarations、references、calls、effects、exits、源码摘要及模块配置。
每条结果关联对象 ID、证据 ID、规则版本、状态、假设和未解析项。
导入名称用于关系构建，不作为本文件自产变量单独计分。

当前已输出每个绑定的读、直接写、属性写、捕获函数、直接引用函数，以及每个函数的捕获、
外部写、未解析引用、IIFE 标志和本地调用影响集合。
属性写保留根绑定和路径，例如 `input.value++` 是 input 的属性读写，区别于 `input = other`。

## 2. 词法作用域与基础档位

1. 建立作用域树；块、循环、catch、函数、类和模块分别登记边界。
2. let/const 保留声明块；var 归入最近的函数提升边界。
3. 参数归入自身函数，函数体局部声明不会错误遮蔽参数默认值的外部绑定。
4. 查找标识符的最近有效绑定；类型、静态属性名和声明位置从引用列表排除。
5. 对未解析引用保留 name 与 range，不将名称相同作为绑定证据。

评分基础档位的细化建议如下，参数版本应显式保存这张映射：

| 声明范围 | 建议档位 | 生效条件 |
| --- | --- | --- |
| 函数参数、函数/块内局部声明 | local | 绑定与提升边界确定 |
| 模块顶层、脚本全局、静态共享成员 | global | 成员/共享类别确定 |
| 实例成员、动态全局 | 待定 | 对象生命周期和绑定仍需解析 |
| 导入、纯类型声明 | 不适用 | 用于关系分析，不直接评分 |

模块私有与导出属性分别记录；基础档位不直接等同于对外可访问性。
`B_local`、`B_global` 作为待标定参数；当前不写入默认分数。

## 3. 纯度分析

后续为每个函数构造摘要 `reads / writes / calls / escapes / throws / nondeterminism`：

1. 直接赋值、复合赋值、更新和 delete 区分本地绑定、捕获绑定、全局及对象属性。
2. 参数或捕获对象的写入进入别名分析；const 只固定绑定，不证明对象不可变。
3. 返回表达式、throw、闭包捕获、异步任务和对象持有形成逃逸证据。
4. getter、代理、运算符隐式转换、外部调用与时间/随机性作为潜在外部行为。
5. 按调用图强连通分量迭代合并摘要至不动点；递归组没有已知副作用也不自动证明终止。
6. 仅当所有相关行为和依赖满足契约时给出 verified；已证明外部副作用为 impure；其余 unknown。

当前只给 `syntax-candidate` 或 unknown。没有显式外部引用或调用不构成纯函数证明，
syntax-candidate 不触发属性加分。外部写入当前仍需区分静态证据与运行时可达性。

## 4. IIFE 与临时性

IIFE 通过语法定位直接调用的函数表达式/箭头函数，允许括号、as、非空及 satisfies 包裹。
识别到立即调用后，仍需检查返回闭包、对象、异步任务、捕获状态及对外写入。
仅当隔离和无逃逸规则已验证时才具有 IIFE 加分资格；IIFE 标志本身不是质量结论。

临时变量算法：

1. 以 CFG 上的定义点和所有使用点计算 reaching definitions 与活跃区间。
2. 对别名、返回、容器写入、回调参数和闭包捕获做逃逸传播。
3. 只有绑定使用范围局部、生命周期满足规则且无越界逃逸时确认 temporary。
4. 内存中的对象生存期与变量词法范围分别记录；未知调用使相关逃逸项保持 unknown。

当前返回引用区间、capture 列表和 `temporary.status=unknown`，不使用引用次数阈值代替生存期。

## 5. 影响链路与去重

建立有向多关系图，节点为绑定/函数/文件/模块，边区分调用、读取、写入、捕获、别名和导入导出。
边按 `(类型, 源, 目标)` 去重；调用频次另存复杂度事实，不增加影响对象数量。

静态画像与修改影响分开：静态画像使用潜在关系；修改影响绑定前后快照，
按签名、实现、导出或共享状态变化选择传播边，输出已知影响与未解析边界。

算法步骤：

1. 选择关系类型和入站/出站方向，构建邻接表。
2. Tarjan 或 Kosaraju 求强连通分量；递归组单独记录大小。
3. 在压缩 DAG 上计算最长已知链路；递归组内循环不充当无限链路长度。
4. 遍历直接、传递影响集合；方法、文件、模块分别按稳定标识去重。
5. 截断时输出下界、预算和边界，不返回完整覆盖结论。

当前只实现文件内已解析词法调用图的正向/反向可达集合及递归标记。
每次遍历预算为 10000 条处理边，超出返回 truncated；尚不输出最长链路或跨文件计数。
外部消费者始终 unknown，不能以“零已知调用方”断言私有或无影响。

## 6. 计分映射与同源收益去重

设有效属性比例为 `p_i`，复用相关计量只在链路项归属：

```text
属性加成 A = B × min(加成比例上限, Σ p_i × verified_i)
链路扣分 D = α log2(1 + 其他受影响方法数)
           + β log2(1 + 其他受影响文件数)
           + γ log2(1 + 其他受影响模块数)
           + δ × 最长已知链路长度 + ε × 已确认状态传播项
S = clamp(B + A − D, 0, 100)
```

本公式细化为待校准规格；α–ε、基础分、比例及上限尚未启用。
同一证据收益只归入一个属性条目；纯度、IIFE、临时性虽可共存，重叠的隔离收益需去重。
纯函数复用、调用次数及跨模块复用不得在属性或位置项再次加扣分。
链路或必需属性覆盖不足时保留已知分项，完整 S 为待定，不默认未知项为零。

## 7. 验收与复杂度

验收覆盖同名遮蔽、var 提升、参数默认值、闭包、属性写入、解构赋值、IIFE 逃逸、
外部调用、递归组、重复引用及截断。纯度和临时性用正例、反例与未知例分别验收。

作用域构建和查找可用作用域哈希表；图构建、SCC 和单次 DAG 遍历为 O(V+E)。
当前逐对象指标聚合使用过滤列表，可达集合按函数重复遍历；规模扩大后应建立引用索引和缓存。
