## 变更内容

- 保留运行前 inject 与运行时／运行后 check 两个编排源，以及路由外置和低干扰边界。
- 将预筛改为 triggered／clear／unknown 三态；缺基线、解析失败、不支持和证据不完整不再有静默通过出口。
- 新增 results.md 与 triggers.md，明确预筛、适用性、审阅结论、覆盖、限制反馈及结果失效。
- 补齐 catalog.json 与 7 个目标路由骨架，空目标索引标记 pending-rules，避免把占位当作已覆盖。
- 目标分发与规则继承分开：两级路由统一引用通用根和同目录专项，不以目标目录下的根文档绕过继承要求。
- 将入口里的最小链路和输入契约要求移入两条初始通用规则，补充当前职责边界、合法可空契约等例外。
- 注入投影必须保留生效条件和例外；预算不足延后完整规则，不能把条件规则裁成无条件禁令。
- 入口只负责编排和建议，检查模式、快照基线和修改后重检要求明确；不将审阅直接变成自动修复授权。
- README、需求与技术方案同步反映实际文件状态，不宣称生成器、差分预筛和 Harness 自动加载已完成。
- 关联信号研究明确候选与违例的边界，不再把单消费方等结构本身称为违规铁证。
