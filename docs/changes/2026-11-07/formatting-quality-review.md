## 变更

- 添加 Prettier／EditorConfig、Python／Rust 格式配置及可重复执行的 format、format:check 命令。
- 统一源码、开发脚本、测试代码与 JSON 的四空格缩进；原生语言使用理解语法的格式化工具。
- 按声明和方法边界补充空行，重点说明评估阶段、协议分帧、跨语言偏移、保守成本、未知传播、源码快照及规则继承。

- 未修改评分策略、预算、职责和模块配置的数据值；不通过填造输入抬高评分。
