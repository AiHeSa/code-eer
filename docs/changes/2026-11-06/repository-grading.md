# 仓库分级评估范围

- 日期：2026-11-06
- 需求：[仓库健康度分级评估](../../requirements/code-review/repository-grading.md)
- 设计：[仓库分级评估设计草案](../../technical-designs/2026-11-06/repository-grading.md)

## 已确认内容

- 仓库分级评估作为其他功能的可选依赖。
- internal 功能和提示词工程功能产出对应评分，并可根据已有仓库等级调整限制。
- 模型评估参照提示词评分方法，对仓库随机部分评分。
- internal 评估按代码逻辑抽取入口和不同叶子功能分支，进行确定性评分。
- 综合两路评分，将仓库分为 A–E 五个等级。
- A 健康度最高，要求更严格；E 健康度最低，适当放宽要求。
- 原始评分保持统一标准。

## 设计进度

抽样复现、评分追溯、等级使用、缺失及失效处理作为设计建议记录。评分维度、权重、等级分界线、抽样细则、入口及功能叶子定义待确定。
