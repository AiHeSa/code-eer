# 三项评分范围

- 日期：2026-11-06
- 需求：[作用域、复杂度与代码位置评分](../../requirements/code-review/scope-complexity-placement.md)
- 设计：[三项评分设计草案](../../technical-designs/2026-11-06/scope-complexity-placement.md)

## 已确认内容

- 作用域单独评分，覆盖纯函数、立即执行函数、局部变量、全局变量、临时变量及影响链路。
- 复杂度单独评分，覆盖时间、空间及循环、递归行为。
- 代码位置按功能模块划分，区分公共与业务文件，纳入入口及叶子节点判断。
- 保留三项评分并合成综合评分。
- 作用域按局部、全局确定基础分，多种有效属性按基础分的百分比加成。
- 常规复杂度中时间权重高于空间，死循环与内存泄漏提高扣分占比。
- 复用场景统一纳入影响链路计量，同一复用影响不得跨维度重复计分。

## 设计进度

基础分累计加成公式、关系图、成本表达式、职责适配、证据追溯和有效性细则作为设计建议记录。

首版权重建议为作用域 45%、复杂度 40%、代码位置 15%；常规复杂度内部建议时间 60%、空间 40%。局部/全局基础分、属性加成比例、严重问题高权重系数、计分映射、预算及聚合方式待标定。

当前交付为需求与设计文档。项目级符号、调用图、数据流、成本分析和评分能力按后续实现任务推进。
