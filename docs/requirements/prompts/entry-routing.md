# 提示词双入口、低干扰边界与分层分发需求

- 日期：2026-11-07
- 状态：入口、契约、两级索引及两条初始通用规则已提供；生成器、差分预筛器和 Harness 加载器待实现。
- 方案：[双入口与分层分发设计](../../technical-designs/2026-11-07/prompt-entry-routing.md)
- 记录：[修正与验证](../../changes/2026-11-07/prompt-entry-routing.md)
- 关联：[抗急性劣化需求](../code-review/evolutionary-resilience.md)

## 1. 目标与执行边界

1. 运行前 inject 提供当前任务的精简预防约束；通用投影预算为 200 Tokens，目标附加预算由适配器配置。
2. 连续编码和调试期间不主动插入审查；check 在一轮编码收尾或提交前执行。
3. 路由、继承、目标识别、阶段投影及预筛在构建期或本地工具内完成，不将完整目录塞入主会话。
4. 注入预算必须包含生效条件与例外；预算不足则延后完整规则，不截断规则语义。
5. 仅在证据完整、全部适用候选预筛为 clear，且无延后或覆盖限制时静默结束；这不等于完整语义合规证明。

## 2. 双入口

- inject：输入任务、范围、先例及已知目标；输出约束、来源、条件与验证事项。
- check：可独立调用，默认 postrun；runtime 处理受影响对象，postrun 核对整个约定检查范围及遗留未决项。
- 入口只编排，不内置具体质量规则；规则正文唯一维护在 prompts/requirements/。
- 审阅结果本身不扩大修改授权；修复后重新绑定快照并检查。

## 3. 两级分发与统一继承

- 保留 routing/catalog.json 与 routing/targets/<target>.json 两级路由，只加载当前命中目标。
- 两级路由引用同一规则文件族，不再使用目标目录下的独立根规则绕开继承约定。
- 通用根为 requirements/<category>/xx.md，专项为同目录 xx.<target>.md，声明 extends: ./xx.md。
- 专项二级条目仅为根条目的子集；通用、语言、框架按条目覆盖，缺项沿用上一层。
- 目标限定规则同样有完整根契约，通过 applicability 限定语言或框架。
- 目标以 config/capability-targets.json 为准；JS/TS 共享索引不抹去精确语言目标。
- 目标索引为空表示该目标规则待编写，必须声明覆盖限制，不能视为通过。

## 4. 预筛与结果

- 信号和规则预筛均区分 triggered、clear、unknown，触发器词汇及必要证据在公共契约定义。
- triggered 是候选，只有进一步审阅才能判定是否违反。
- 缺基线、解析失败、能力不支持、未解析关系、超时或证据不完整均不能返回 clear。
- unknown 定向补证或保留 partial；规则源缺失、非法依赖等配置错误返回 failed。
- 规则 ID 跨阶段唯一；预筛记录和语义审阅结论分别存储，不混用 clear 与 satisfied。
- 完整证据和覆盖账本外置；有未决项时提供必要限制说明，不输出冗长合规清单。
- 结果绑定源码、依赖证据、目标、规则及分析器版本，相关变化导致旧结果失效。

## 5. 验收与当前范围

- 源文件引用、目标映射、规则 ID、依赖、阶段和信号 ID 一致；没有悬空来源。
- 命中规则的条件与例外在投影和预算裁剪后保持完整。
- 专项缺项回退正确，额外二级条目和非法目标被继承校验拦截。
- 静态候选不会直接变成违例；未加载、预筛 clear 或 unknown 不会冒充语义验证已满足。
- 现有继承校验仅检查识别出的通用／专项文件族，不能代替后续目录、投影和覆盖校验。
- 当前仅有两条初始通用规则和空目标索引；尚不提供全语言覆盖、自动预筛或自动触发承诺。
