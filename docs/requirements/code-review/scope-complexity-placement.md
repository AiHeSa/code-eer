## 1. 已确认的功能范围

基于 AST 结果、变量与方法的位置及其影响范围，分别产生作用域、复杂度、代码位置三项评分，并合成为综合评分。

| 评分 | 评估内容 |
| --- | --- |
| 作用域 | 纯函数、立即执行函数、局部变量、全局变量、临时变量及其影响链路 |
| 复杂度 | 时间复杂度、空间复杂度，参考循环与递归行为 |
| 代码位置 | 按功能模块区分公共文件与业务文件，结合入口、叶子节点等位置 |

作用域评估包含改动可能影响的方法、文件及整体链路长度。三项原始评分与综合评分均保留。

### 已确认的评分约定

- 作用域基础评分按局部、全局两档确定；多种属性按基础分的百分比加成，形成综合的作用域评分。
- 常规复杂度评分中，时间的权重高于空间。
- 死循环与内存泄漏使用高权重严重问题规则，提高对应问题的扣分占比。
- 复用场景统一进入影响链路计量；复用造成的影响范围不得在其他维度重复计分。

## 2. 属性与评估对象建议

以下内容为待确认的设计建议。

- 对象类别使用变量、函数和方法；声明位置、引用位置和所属功能模块随对象记录。
- 作用域使用块、函数、模块、全局等范围；纯度、立即执行、临时性作为可组合属性。
- 纯函数评估结果记录为已验证、条件成立或未知，并保留所依赖的调用与状态假设。
- 立即执行函数记录捕获、共享状态修改、返回值逃逸及异步行为。
- 临时变量记录实际生存期、引用范围及逃逸情况；局部变量可同时具有临时属性。
- 模块级变量、进程全局变量及对象共享状态分别记录。
- 函数或方法以函数体及约定的调用范围为评估单元；变量的计算范围需明确到初始化、更新或使用点。
- 不同对象的评分保留评估单元与适用性，综合及聚合规则按同一口径执行。

## 3. 三项评估建议

### 作用域

- 结合声明可见性、实际引用、读写行为、共享状态、闭包捕获、别名和逃逸评估影响范围。
- 分别记录直接与传递影响的方法数、文件数和模块数，以及链路长度。
- 入站依赖与出站调用分别记录；依赖可达范围与具体改动推导出的影响分别记录。
- 修改场景区分声明签名、实现、读写及导出变化，并绑定修改前后快照。
- 局部、全局基础分结合有效属性的百分比加成及链路影响形成作用域分；具体数值与链路扣分映射待标定。
- 复用通过调用与引用关系进入链路，直接与传递调用方、影响文件及模块按稳定标识去重。
- 纯度与状态隔离作为属性加成依据，复用范围使用链路指标计量。
- 动态调用、外部消费者和分析边界保留未解析状态。

### 复杂度

- 时间和空间分别产生子评分；输入规模使用具名变量，例如记录数 n、边数 m。
- 常规时间权重高于空间；死循环与内存泄漏分别记录高权重扣分贡献及证据。
- 记录循环边界、连续与嵌套执行、递归分支、递归深度、缓存和调用次数。
- 空间记录峰值辅助空间，包含调用栈；输入、输出及辅助空间分别列示。
- 评估记录复杂度结论、成立条件、证据和未知项。
- 严重问题区分已证实、疑似及未知；死循环结合退出、取消及生命周期契约判断，内存泄漏结合对象存活与释放责任判断。
- 评分结合任务规模、算法职责和已声明的成本预算；增长阶、具体成本与预算符合度分别列示。
- 时间与空间预算、增长阶到分数的映射及缺少预算时的评分规则待确定。

### 代码位置

- 以功能模块边界识别入口、编排、中间处理和叶子节点，支持多种角色并存。
- 文件职责区分公共与业务；共享范围和模块归属独立记录。
- 结合角色评估职责适配：入口的契约与编排、公共能力的共享边界、叶子功能的局部职责。
- 目录、名称、配置、导出及调用关系共同提供位置证据；关系不足时保留候选角色。
- 位置项使用职责适配程度评分，影响范围和执行成本使用各自维度的计分项。

## 4. 综合与使用建议

- 三项使用 0–100 分，分数越高表示对应质量越好。
- 首版权重建议为作用域 45%、复杂度 40%、代码位置 15%。常规复杂度内部建议时间 60%、空间 40%；严重问题的高权重规则单独配置。
- 权重、各项评分规则和适用条件共同版本化，参数经代表性样例校准后确定。
- 完整综合分要求必需项有效；缺失、未知及不适用分别记录，综合结果保留有效性状态。
- 相同事实、规则和配置下，原始评分保持一致；仓库 A–E 等级用于选择后续执行限制。
- internal 与提示词工程使用相同维度标识和证据约定，各自保留评分来源。
- 通用能力定义入口，语言和框架专项继承通用契约，缺项按通用能力处理并保留能力覆盖情况。

## 6. 建议验收标准

- 同名遮蔽、闭包捕获、变量逃逸、全局读写及对象属性修改具备对应证据。
- 立即执行函数的状态修改、纯函数的外部调用及未解析依赖按实际行为产生结果。
- 同一对象的有效属性按基础分累计百分比加成，结果保留基础分、各项加成、链路调整及封顶信息。
- 影响对象去重；循环依赖、递归组、链路截断和未解析关系均可查看。
- 同一复用关系在链路中归属明确，位置及属性项不得再次按复用数量加扣分。
- 固定次数循环、连续循环、不同规模的嵌套循环及递归分别按成本表达式验证。
- 递归栈、缓存及输出规模在空间分析中具有明确归属。
- 常规复杂度保持时间优先；死循环、内存泄漏按严重规则验收，同一证据的重复扣分受到校验。
- 约定的常驻循环、终止性未知、预期缓存与已证实泄漏具有各自的判定结果和证据。
- 公共叶子与业务入口按对应职责评估；候选叶子保留关系覆盖状态。
- 综合分可追溯三项及子项贡献，未知项和不适用项按明确策略处理。
- 同一原始评分在不同仓库等级下保持一致；通用及专项实现通过继承校验。
