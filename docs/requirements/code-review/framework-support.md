## 1. 范围与定位

- **支持目标与后端复用**：首批支持 React 与 Vue 3 两大前端框架。两者均复用 JS/TS 后端的底层语言解析能力，并通过各自的框架适配器提取组件结构与视图结构。
- **四类能力状态细分**：系统按**脚本解析**、**视图解析**、**框架结构提取**和**框架语义能力**四个维度，分别记录并汇报各框架的支持状态。
- **版本锁定与框架识别**：React 与 Vue 解析工具包的实际版本、Node.js 运行时要求及可解析语法范围，均在接入验证时锁定。React 项目识别综合参考显式配置、项目依赖与源码导入；JSX 文件的分析结果需保留框架识别结论及识别依据。

## 2. React 支持要求

- **文件与代码覆盖范围**：支持 `.jsx`、`.tsx` 文件，以及项目配置允许包含 JSX 的 `.js` 文件；普通 `.js` / `.ts` 文件中的 React 框架用法（如自定义 Hook、Context 等）同样纳入结构提取范围。
- **JSX 视图结构提取**：提取 JSX 元素、片段（Fragment）、属性（Props）、展开属性（Spread Attributes）、表达式容器、子节点层级及对应的源码位置。
- **组件识别与导入导出**：识别并提取函数组件、类组件及组件导入导出关系，同时记录组件的识别依据与无法静态确定的候选项。
- **Hook 调用证据提取**：提取 Hook 调用的语法证据，包括导入来源、导入别名和调用位置；自定义 Hook 的识别依据单独记录。
- **JSX 组件目标解析**：区分 JSX 标签在源码中的字面名称与解析后的实际组件定义目标（跨文件组件目标解析依赖底层符号分析能力）。
- **组件属性（Props）与类型**：将组件属性的“语法层声明”与“实际解析出的类型”分开表达；输出类型结果时一并附带当前可用的语义能力状态与项目配置。
- **具体审查规则解耦**：Hook 调用合法性（Rules of Hooks）、依赖数组检查及其他生产级审查规则，在对应的独立规则需求中另行定义。

## 3. Vue 3 支持要求

- **单文件组件（SFC）解析**：支持 `.vue` 单文件组件，准确识别并拆分 `template`、`script`、`script setup`、`style` 及自定义区块（custom blocks）。
- **脚本写法覆盖**：支持 JS / TS 脚本、普通 `<script>` 与 `<script setup>` 共存场景，同时覆盖 Composition API 与 Options API 两种写法下的结构提取。
- **模板视图结构提取**：提取模板中的普通元素、组件使用、属性绑定、指令、文本插值、事件监听、插槽（Slot）及内嵌表达式。
- **指令细节完整保留**：保留 `v-if`、`v-for`、`v-model` 等指令的原始名称、参数（静态或动态）、修饰符（Modifiers）以及表达式在源码中的位置。
- **组件接口与编译器宏**：提取 `props`、`emits`、组件导入、组合式函数（Composables）调用，以及 `defineProps`、`defineEmits` 等编译器宏的语法证据。
- **模板与脚本作用域区分**：区分模板内的循环变量（如 `v-for`）、插槽参数（`v-slot`）与脚本顶层绑定的各自作用域；模板标识符到脚本绑定的跨区解析作为独立能力项记录。
- **Vue JSX / TSX 支持**：对 Vue 场景下的 JSX / TSX 输入文件，需结合显式配置或可追溯的框架识别依据进行处理，并在结果中保留 Vue 框架标记。
- **模板与脚本语言基线**：首批视图模板基线为标准 HTML 模板，脚本基线为 JS / TS；其他预处理语言（如 Pug 等）按实际可用适配器声明支持状态。
- **样式与自定义区块处理**：`style` 与自定义区块在首批实现中记录区块属性（如 `scoped`、`lang`）、语言类型及源码位置；CSS 审查及自定义区块内容分析按独立能力扩展。
- **外部 `src` 区块加载**：通过 `src` 引用外部文件的区块，按项目根目录、路径访问边界及包含/排除配置进行加载；结果中需记录关联的外部文件，缺失文件或受限路径记入错误或未执行项。

## 4. 结构模型与源码位置映射

- **公共模型与框架扩展空间**：公共结构模型统一承载组件、视图元素、属性、数据绑定、指令和脚本声明；框架特有的专属字段存放在具备 Schema 约束的扩展空间中。
- **事实溯源与三类关系区分**：每条结构事实均保留输入文件、内容摘要、原生 AST 节点类别及框架来源。组件事实可关联对应的函数或类声明；结构上的**父子包含关系**、**源码字面引用关系**与**已解析的符号指向关系**分别独立表达。
- **Vue SFC 源码位置重映射**：Vue 单文件组件的区块位置、脚本内偏移量和模板节点位置，统一换算并映射回原始 `.vue` 文件。外部 `src` 区块的事实定位到对应的外部文件，并保留其与所属 `.vue` 组件的关联关系。经过预转换的代码需保留来源映射（Source Map）及其覆盖状态。
- **分模块状态与整体完成度**：脚本解析、模板解析和区块加载分别返回结果。当请求的能力未能全部完成时，整体任务状态按 AST 契约返回 `partial`（部分完成）、`failed`（失败）或 `cancelled`（已取消），并列出具体原因。

## 5. 验收标准

- **React 核心场景**：覆盖 JSX / TSX 解析、函数组件与类组件识别、Fragment 片段、展开属性、嵌套表达式、Hook 导入别名，以及与 Hook 同名的普通函数区分。
- **Vue 3 核心场景**：覆盖普通 `<script>`、JS / TS `<script setup>`、双脚本共存、Composition API、Options API、模板指令解析及插槽作用域提取。
- **通用边界与降级场景**：两种框架均覆盖组件导入导出、项目配置缺失、源码语法错误，以及跨文件符号解析受限时的降级表现。
- **Vue 异常与动态场景**：覆盖 Vue 单个区块独立解析失败、外部 `src` 引用缺失、不支持的预处理语言，以及 `<component :is="...">` 动态组件目标无法静态确定时的处理。
- **多字节编码与位置精度**：使用包含中文、Emoji、CRLF 换行符及多区块混排的源码文件，验证原始源码位置映射与内容摘要截取的准确性。
- **消费契约一致性**：通过最小消费端用例验证公共组件结构字段与框架专属扩展字段的读取一致性；具体代码审查规则在对应规则需求中验收。
