## 1. 范围

首批支持 React 与 Vue 3。两种框架复用 JS/TS 后端的语言能力，并通过框架适配器提供组件和视图结构。支持状态分别记录到脚本解析、视图解析、框架结构提取和语义能力。

React 与 Vue 工具包的实际版本、Node.js 要求及可解析语法范围在接入验证时锁定。React 项目识别结合显式配置、依赖和源码导入；JSX 文件需保留框架识别结果及依据。

## 2. React

- 覆盖 `.jsx`、`.tsx`，以及项目配置允许包含 JSX 的 `.js` 文件；普通 `.js` / `.ts` 中的框架用法同样参与结构提取。
- 提取 JSX 元素、片段、属性、展开属性、表达式容器、子节点及源码位置。
- 提取函数组件、类组件及组件导入导出；记录识别依据与未确定项。
- 提取 Hook 调用的语法证据，包括导入来源、别名和调用位置；自定义 Hook 的识别依据单独记录。
- 区分 JSX 中的源码名称与已解析的组件目标；跨文件组件目标依赖符号能力。
- 组件属性的语法声明与实际类型分别表达；类型结果附带可用能力和项目配置。
- Hook 合法性、依赖数组检查及其他生产审查规则在对应规则需求中定义。

## 3. Vue 3

- 支持 `.vue` 单文件组件，识别 `template`、`script`、`script setup`、`style` 和自定义区块。
- 支持 JS / TS 脚本、普通脚本与 `script setup` 共存，以及 Composition API 和 Options API 的结构提取。
- 提取模板元素、组件使用、属性、指令、插值、事件、插槽及嵌入表达式。
- 保留 `v-if`、`v-for`、`v-model` 等指令的原始名称、参数、修饰符和表达式位置。
- 提取 props、emits、组件导入、组合式函数调用，以及 `defineProps` / `defineEmits` 等编译器宏的语法证据。
- 模板中的循环变量、插槽参数与脚本绑定具有各自作用域；绑定解析作为独立能力记录。
- Vue JSX / TSX 输入需使用显式配置或可追溯的框架识别依据，并保留 Vue 框架标记。
- 首批模板基线为 HTML 模板、脚本基线为 JS / TS；其他预处理语言按可用适配器声明支持状态。
- `style` 和自定义区块首批记录区块属性、语言与位置；CSS 审查及自定义区块内容分析按独立能力扩展。
- 外部 `src` 区块按项目根目录、路径访问范围与包含排除配置加载；记录关联文件，缺失文件或受限路径进入错误或未执行项。

## 4. 结构与位置

公共结构模型容纳组件、视图元素、属性、绑定、指令和脚本声明；框架专属字段置于具备 Schema 的扩展空间。

每个事实保留输入文件、内容摘要、原生节点类别及框架来源。组件事实可引用对应的函数或类声明；包含关系、源码引用和已解析符号关系分别表达。

Vue SFC 的区块位置、脚本偏移和模板位置统一映射到原始 `.vue` 文件。外部区块的事实定位到对应外部文件，并保留 SFC 关联。经过转换的代码保留来源映射及其覆盖状态。

脚本、模板和区块加载分别返回结果。请求能力未完成时，整体状态按 AST 契约返回 `partial`、`failed` 或 `cancelled`，并列出原因。

## 5. 验收

- React：JSX / TSX、函数与类组件、片段、展开属性、嵌套表达式、Hook 导入别名与同名普通函数。
- Vue 3：普通脚本、JS / TS `script setup`、双脚本、Composition API、Options API、模板指令和插槽作用域。
- 两种框架均覆盖组件导入导出、项目配置缺失、语法错误与跨文件符号能力受限。
- 验证 Vue 各区块的独立失败、外部 `src` 文件缺失、不支持的预处理语言及动态组件目标未确定。
- 使用中文、emoji、CRLF 与多个区块验证原始源码位置和内容摘要。
- 以最小消费用例验证公共组件结构及语言专属字段；审查规则另行验收。
