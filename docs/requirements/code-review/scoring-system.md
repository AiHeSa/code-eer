## 1. 本轮目标

将已有 AST 证据与三项算法连接为可追溯、可复现的评分系统设计。
评分核心通过编程接口供后台服务调用，本轮不扩展 CLI 和前端。
范围包含作用域 S、复杂度 C、代码位置 P，以及三项综合分。

## 2. 必需行为

- 对象、文件、模块及仓库分别保留结果及明确的聚合单元，证据不脱离源码快照。
- 原始事实、语义推导、规则判定和数值映射分层，语法候选不自动升级为语义证明。
- 每项规则保留执行状态、适用性、判定、证据、假设和未满足的前提。
- 未知、不支持、失败和不适用分别表达；不把未知项转换成满分、零分或通过。
- 规则、参数、预算、职责契约和聚合策略独立版本化。
- internal 与模型结果保留来源，同一维度按来源合成，重叠证据有归属。
- 仓库等级只选择下游执行限制，不反向改变本次原始评分标准。
- 已确认严重问题有独立约束，保留原始合成值和约束后的值。
